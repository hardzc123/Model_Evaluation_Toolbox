# Standard Benchmarks Example

Run industry-standard benchmarks (MMLU, HumanEval) on models.

## Running

```bash
# Run MMLU benchmark
python run_mmlu_benchmark.py

# Run HumanEval benchmark
python run_humaneval_benchmark.py
```

## Benchmarks

- **MMLU**: Tests knowledge across 57 subjects
- **HumanEval**: Tests code generation capability

Note: These benchmarks may take significant time and API costs to complete.
