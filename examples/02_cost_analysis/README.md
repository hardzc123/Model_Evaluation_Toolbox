# Cost Analysis Example

This example demonstrates how to analyze and compare costs across different models.

## Running the Example

```bash
python run_cost_analysis.py
```

## What This Example Does

1. Compares costs across multiple models for the same workload
2. Calculates per-request and monthly costs
3. Computes cost efficiency (quality per dollar)
4. Ranks models by value

## Output

The script generates:
- Cost comparison table
- Monthly cost estimates
- Cost efficiency rankings
- Best value recommendations
